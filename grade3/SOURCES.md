# 三年级学习系统：教材范围、实现与验证

本次在原有 `grade3` 网站保留配色、成长伙伴和宠物动画，重建教材目录、题目元数据与学习状态机。所有新增题目为本次编写或参数化生成，不复制第三方题库数据，不声称经过出版社审核。

## 教材范围

- 语文：部编版三上修订版，保持原站“预测”第三单元、“童话”第四单元的顺序，含《犟龟》《宝葫芦的秘密（节选）》。出版社对这次修订的说明：https://www.pep.com.cn/bks/xxyw/jzjd/202510/W020251016516675066625.pdf 。这不是对用户实体教材逐页核验的声明。
- 数学：北师大版三上“混合运算”起始目录：混合运算、观察物体、加与减、乘与除、周长、乘法、年/月/日、认识小数。核对目录：https://www.haoduoyun.cc/book/bsb/shuxue/sannianji_3s/5.shtml 。删除原站将面积、分数、盈亏、相遇追及、鸡兔同笼等混入本册常规训练的做法。
- 英语：外研版（三起）三上 Module 1—10，参考单词表目录 https://www.haoduoyun.cc/book/waiyanban/yingyu/3a/68.shtml 和外研社教材书目 https://www.fltrp.com/ebook/jcjyyjzx/2023_jcjyjxzy/files/basic-html/page174.html 。同时保留原站 Welcome/Unit 1—6 新教材模式，两者使用不同的单元和知识点ID，用户在英语入口选择，报告不混算。未取得用户实体课本出版年份，目录以页面明确显示的版式为准。

阅读与写作练习包含原创迁移情境；选择题测写作方法，不把选择题成绩冒充实际作文、朗读或听力能力。

## GitHub 开源调研

1. https://github.com/Khan/perseus （MIT）：题目数据、交互呈现、判分分离。本项目采用独立 data.js、engine.js、app.js，不引入整个编辑器。
2. https://github.com/learningequality/kolibri ：参考练习和掌握度记录的产品组织方式。这里采用公开说明的“不同题样本数＋最近8次＋待巩固错题”启发式规则，不声称实现其算法或心理测量模型。
3. https://github.com/Khan/khan-exercises ：参考参数化生成不同练习。该项目已停止新练习开发；框架MIT、练习CC BY-NC-SA，未复制其练习内容。
4. https://github.com/wuwangzhang1216/ChinaTextbookStudyFree ：参考按单元组织知识重点、即时反馈、游戏化。其数学为人教版、英语为PEP，不作为本系统北师大数学/外研英语的内容来源。未下载其教材原页、音频或AI题库。
5. https://github.com/JeetChan/mini-classroom ：参考纯静态、小学交互式练习的轻量设计；其通用英语并非本任务指定课本，不混入本题库。

## 学习闭环和记录

每题有稳定ID、学科、章节、知识点、答案、解析。普通练习优先未做过的题。错题按题ID合并，不重复堆积。重做包含原题、3道相同知识点的不同题、2道不同的复测题，组内不会重复；有限题库用尽后可以再次练旧题，但不冒充全新题。

至少5道不同题、最近最多8次作答正确率达到80%、没有待巩固错题，才显示“已掌握”；样本不足单独标注。单题巩固并不等于整个知识点掌握。报告的学科和章节正确率按作答次数加权，显示当前教材数据。

`grade3LangState` 旧记录保持原样，新记录存入 `grade3LearningV3`。迁移宠物与星星，旧错题可查看；旧题缺少可靠单元和知识点标识，不映射成新版成绩。题目、选项、输入草稿、已答状态及复习阶段随作答保存。保存失败提示下载备份；损坏原记录不覆盖。

## 验证

运行 `node grade3/build.cjs`、`node grade3/test.cjs`；界面验证脚本 `ui-test.cjs` 的浏览器依赖路径为本次Windows环境，可按环境修改。`test-results.json` 与 `ui-test-results.json` 为实际测试结果。

覆盖题目唯一性、选项唯一性、答案存在、每知识点至少6题、数学禁入范围、重复点击、错题失败/成功分支、刷新恢复、损坏与拒绝存储、旧记录迁移、掌握度、选项位置；浏览器覆盖三科、章节、学习、输入/选择、判分解析、完整错题闭环、报告下载、宠物、390px手机和820px平板。

题库是可持续补充的基础练习集，不等同于教材每道课后题或全套考试题；听力、真实作文与纸笔操作需要另行评价。
