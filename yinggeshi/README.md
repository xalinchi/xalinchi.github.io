# 英歌石科创基地网站

部署位置：xalinchi/xalinchi.github.io 的 /yinggeshi/。纯静态文件，无构建依赖；沿用现有 GitHub Pages 发布方式，不修改根目录主页或其他站点。

## 维护

- `index.html`：页面入口与无障碍跳转。
- `style.css`：响应式视觉样式。
- `content.js`：双语栏目、子栏目及 PPT 录入清单。
- `app.js`：路由、语言切换、全文标题/来源搜索、分类筛选。

本地通过任意静态服务器打开此目录。八个栏目使用哈希路由，刷新无需服务器重写。

数据依据上传的《英歌石科创基地官方网站设计方案(1).pptx》（2026年10月），保留22条不同的录入条目。开城新闻在PPT中有2026-03-23和2024-10-16两个日期，已合并并明确展示冲突。所有正文、原文URL、日期仍须官方核验；未提供的联系方式、学校标识、基地照片/地图、平台团队详情与知识产权等均明确占位。英文为参考译文，正式英文名称待确认。没有虚构新闻正文、地址、电话或官方平台名称。

补充内容时，在 content.js 维护条目及中英译文，在 app.js 中接入经核验的正文和URL。当前仅提供前端内容维护，不含后台或提交表单。
