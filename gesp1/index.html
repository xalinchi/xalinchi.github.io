高频易错点

  • 整数除法：7/2 得3；至少一个操作数为浮点数才得3.5。
  • 自增：i++ 先使用后加；++i 先加后使用。复杂表达式尽量拆开。
  • 逻辑优先级：! 高于 &&，高于 ||；拿不准就加括号。
  • 循环边界：i<n 与 i<=n 相差一次；手算首、末、次数。
  • 死循环：检查循环变量是否真的向终止条件靠近。
  • 嵌套循环：总次数不是简单相加；内层每次都会重新执行。
  • 字符与数字：'7'不是整数7；转数字用'7'-'0'。
  • 类型转换：强转只作用于指定表达式；先乘再除可减少整除截断。
  • 数学函数：ceil向上取整，floor向下取整；负数尤其易错。
  • 分支覆盖：多个独立if可能同时执行；互斥情况用if/else if/else。

客观题稳分技巧

  1. 先圈出题目问的是“正确”还是“不正确”。
  2. 代码题建变量表，一行一行写值，不凭感觉跳步。
  3. 循环先算执行次数，再算每次变化；嵌套循环画两列。
  4. 遇到ASCII，牢牢记住数字、大写、小写各自连续，'0'=48。
  5. 判断题出现“总是、一定、任何”时，主动找反例。
  6. 不会的先标记，客观题每题最多停留约1.5分钟。

编程题拿分清单

读输入输出 → 手算样例 → 写边界 → 选合适类型 → 完成后测最小值、最大值、临界值。先写能得部分分的正确循环，不要空题。
